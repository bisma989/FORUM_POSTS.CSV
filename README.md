# Week 8: Sentiment Model Evaluation & Error Analysis

This project focuses on evaluating a sentiment analysis model, identifying failure modes (False Positives, Sarcasm, and Ambiguity), and applying a confidence threshold filtering mechanism to improve production reliability.

## Project Structure
- `data/`: Contains raw test data and final evaluated results.
- `src/`: Contains modular scripts for error analysis and confidence filtering.
- `outputs/`: Stores failure analysis logs and the final report.
